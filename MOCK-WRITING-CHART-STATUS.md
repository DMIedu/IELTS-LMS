# Private Writing chart delivery draft

A reviewed paper may attach a bounded grouped bar chart to a Writing question. The backend validates labels, finite non-negative values, category/series counts and scale before starting a paper. It returns a strict chart allowlist only with the current section, excluding unknown fields and keys. Candidate and teacher drafts render the same data with SVG text/numeric geometry and an accessible exact-values table. No arbitrary HTML, SVG or resource URL is accepted.

Mock 01's original Writing tasks and chart are adapted in an owner-only Google Doc; actual question/chart data remain outside the public repo. The adapter is a section fragment, not a complete MockPapers row. Merge with the separately adapted Listening/Reading sections and review before installing. Reviewed and AudioReviewed remain false; runner remains disabled. Mock 02 chart extraction and both mocks' Listening delivery/Speaking remain incomplete.
