# Private Writing chart delivery draft

Reviewed private Writing questions can carry bounded grouped bar or line charts. Bar charts allow up to six categories; line charts allow two to sixteen. Both allow up to four series and require finite non-negative values within the declared scale. Optional line forecast boundaries must be integer category positions from one through the last index. Unknown fields/keys are stripped and charts are restricted to Writing.

Candidate and teacher drafts share safe numeric SVG rendering and exact-values tables. Line charts preserve trend coordinates and identify the projected region in the chart and table caption. No arbitrary HTML, SVG or resource URL is accepted. Original paper/chart data remain outside the public repository.
