# Isolated DMI website test

Extract the whole ZIP; double-click Start-DMI-Test.cmd. Keep the server window open.
Open http://127.0.0.1:8765/test-start.html if the browser does not open automatically.
Use only temporary Security Test accounts. No production endpoint is selected.
No installations/admin access. Close launcher to stop; do not run inside ZIP.
Local PowerShell server is not runtime-tested: Codex local execution is unavailable.
If Windows blocks the launcher or shows an error, send the message; do not bypass machine policy.
Pages are based on the security draft, with test URL, labels and separate auth-cache keys.
The browser guard blocks alternate script.google.com paths. Main/Pages are unchanged.
External media remains on original content hosts. Some local media files were never
present in the repository; missing media is not proof of a session/backend defect.
Package contains original public repo files; do not use its backend Code.gs on production.
